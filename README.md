# Fathima Sahthiya – Personal Portfolio Website

A recruiter-friendly, responsive, animated personal portfolio website tailored for **Fathima Sahthiya** targeting the **Associate Software Engineer** role, with a focus on Java and backend software engineering.

---

## Key Features & Positioning

- **Light & Dark Mode**: Seamless toggle between refined dark navy and clean airy light theme, persisting user preference to `localStorage`.
- **Target Role Focused**: Clearly introduces Fathima Sahthiya as a BEng Software Engineering graduate seeking an Associate Software Engineer role.
- **Strict Factual Accuracy**:
  - London Metropolitan University (BEng 2024, Second Class Upper).
  - TechCodz PVT LTD IT Lecturer role documented with exact dates (**February 2025 – January 2026**).
  - Project Manager role (**January 2024 – February 2025**) accurately framed as project coordination without claiming hands-on software engineering.
- **Highlighted Projects with Icons**:
  - **Car Racing Event Management System**: Desktop Java application with Trophy icon.
  - **Hospital Management System (Arogya Health Care)**: Healthcare web portal with HeartPulse icon.
  - **Crop Diagnostic Mobile Application**: Agricultural assistant with Sprout icon.
- **Transparent Portrait**: Clean background cutout with soft anti-aliased edge feathering, breathing ambient backlight aura, and floating levitation micro-badges.
- **Interactive Skills Explorer**: Live search bar and category tabs allowing recruiters to filter technologies on the fly.
- **Scroll Progress & Floating Navigation**: Real-time progress bar at the top and floating quick-connect action pill.

---

## Tech Stack

- **Framework**: React 18 with TypeScript
- **Styling**: Tailwind CSS (with `class` dark mode support)
- **Icons**: Lucide React
- **Motion**: Motion for React (`motion`) with reduced-motion fallback

---

## Local Development & Preview

```bash
# 1. Install dependencies
npm install

# 2. Start local development server
npm run dev

# 3. Build for production (typecheck + bundle)
npm run build

# 4. Preview the production build locally
npm run preview
```
